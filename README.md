# Practice Assignment 6

- `nextjs-backend/`: the supplied NestJS Todo API, unchanged.
- `todo-frontend/`: the completed Next.js 16 routing exercises.

Run these commands in separate terminals from this repository directory:

```powershell
cd nextjs-backend
npm.cmd install
npm.cmd run start:dev
```

```powershell
cd todo-frontend
npm.cmd install
Copy-Item .env.example .env.local
npm.cmd run dev
```

Open http://localhost:3001. See [the frontend README](todo-frontend/README.md)
for the exercise map and verification checklist.
